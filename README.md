📌 Project Overview

This project focuses on analyzing a company's financial performance using financial statements and key financial metrics.

The analysis covers revenue, gross profit, operating expenses, EBITDA, profitability, liquidity, working capital, and debt, with the objective of understanding the company's overall financial position and performance.

🎯 Objectives
Analyze revenue and sales performance
Calculate gross profit and gross profit margin
Analyze operating expenses
Calculate EBITDA and EBITDA margin
Evaluate profitability
Analyze liquidity and working capital
Calculate debt-related financial ratios
Identify financial trends and performance changes
Build an interactive financial dashboard
